# Adhishrihaan Foundation – Homepage Replica

This project recreates the homepage layout and visual style of the reference website using HTML, CSS, JavaScript and Bootstrap 5.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3
- Bootstrap Carousel
- Bootstrap Grid System
- Bootstrap Responsive Utilities

## Bootstrap Components Used

Bootstrap is used throughout the project for the responsive structure and UI components, including:

- Responsive Navbar
- Mobile Navigation / Collapse
- Dropdown Menus
- Carousel
- Responsive Grid System
- Containers
- Buttons
- Flexbox Utilities
- Spacing Utilities
- Responsive Images

Custom CSS is used alongside Bootstrap to match the visual appearance of the reference website, including colors, typography, spacing, cards, image treatments and hover effects.
